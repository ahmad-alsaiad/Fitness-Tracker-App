# Design System & Token Reference

## Color Palette Tokens
- Background Canvas: `#0A0D14`
- Surface Cards / Containers: `#141A29`
- Borders / Dividers: `#242E45`
- Primary Brand Accent: `#FFAE75` (Sandy Orange — *Note: Text placed on primary accent buttons must use `#0A0D14` for high contrast*).
- High Emphasis Text: `#F1F5F9`
- Muted / Supporting Text: `#9E9E9E`
- Semantic Success / PR / Justified Tag: `#34D399` (Emerald Mint)
- Semantic Danger / Unjustified Tag: `#F87171` (Coral Red)

## Typography & Component Standards
- Font: System sans-serif stack optimized for mobile readability.
- Layout: Mobile-first padding, rounded cards (`rounded-xl` or `rounded-2xl`), subtle borders (`border border-subtle`), and sticky bottom navigation bar with 5 icons (Overview, Workouts, Progress, Photos, Review).
